  Conceptual comparison of the 4 JDBC driver types:
  +------+---------------------------+----------------------------------------+
  | Type | Name                      | How it works / verdict                 |
  +------+---------------------------+----------------------------------------+
  |  1   | JDBC-ODBC bridge          | Java->ODBC->DB. Removed in Java 8. Dead|
  |  2   | Native-API driver         | Java->C client lib->DB. Platform-bound |
  |  3   | Network-protocol driver   | Java->middleware server->DB. Flexible  |
  |  4   | Thin (pure Java) driver   | Java->DB wire protocol directly.       |
  |      |                           | Portable & fastest -> USED TODAY       |
  +------+---------------------------+----------------------------------------+
  MySQL Connector/J is a Type-4 thin driver.
