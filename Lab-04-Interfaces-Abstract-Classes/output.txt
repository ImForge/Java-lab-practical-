===========================================================
  I am a Rectangle, a polygon with 4 sides.

  (Circle has no describe(): it is not a Polygon - by design.)

===========================================================
 3. MULTIPLE INTERFACE IMPLEMENTATION - Shape + Drawable
===========================================================
  Drawing Circle    : ( O )  radius=5.0
  Drawing Rectangle : [=====]  8.0 x 3.0
  Circle implements Shape AND Drawable directly;
  Rectangle gets Shape via Polygon and adds Drawable - both legal.

===========================================================
 4. INTERFACE vs ABSTRACT CLASS - observed comparison
===========================================================
  Interface Shape   : only a contract (area/perimeter) + default method;
                      a class may implement MANY interfaces.
  Abstract Polygon  : holds STATE (sides) + concrete describe();
                      a class may extend ONLY ONE abstract class.
  Polymorphism works through both: Shape[] held all three shapes above.
